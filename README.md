# Smart Job Placement & Recruitment Management System

A full-stack React application with a Node.js/Express backend for managing recruitment, candidates, interviews, and placements.

## Tech Stack

- React + Vite frontend
- Express backend
- REST API connectivity
- Responsive dashboard UI

## Getting Started

1. Install dependencies:
   npm install
2. Run the app:
   npm run dev
3. Open the frontend in your browser at http://localhost:5173
4. The API is served at http://localhost:5001/api

## Scripts

- `npm run dev` – starts both backend and frontend
- `npm run build` – builds the frontend for production
- `npm run start` – runs the backend only
